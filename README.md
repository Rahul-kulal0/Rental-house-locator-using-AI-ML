# 🏠 Rental House Locator Using AI/ML

A full-stack web application that helps users search for rental properties and predicts rental prices using Machine Learning. The application provides an intuitive interface for browsing houses, applying advanced filters, viewing locations on a map, and estimating rental prices based on property features.

---

## 📌 Features

* 🔐 User Authentication (Register/Login)
* 🏠 Browse rental properties
* 🔍 Advanced search and filtering
* 📍 Interactive map integration
* 🤖 AI-based rent price prediction using Random Forest
* 📌 Nearest house recommendation using KNN
* 💾 MongoDB database integration
* 📱 Responsive user interface
* ⚡ RESTful API architecture

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Rahul-kulal0/Rental-house-locator-using-AI-ML.git
```

### Navigate to the project

```bash
cd Rental-house-locator-using-AI-ML
```

### Install frontend dependencies

```bash
cd frontend
npm install
```

### Install backend dependencies

```bash
cd ../backend
npm install
```

### Start the backend server

```bash
npm start
```

### Start the frontend

```bash
cd ../frontend
npm start
```

## 🤖 Machine Learning Model

The project uses a **Random Forest Regressor** to predict rental prices based on multiple property attributes such as:

* House Type
* House Size
* Location
* Number of Bathrooms
* Number of Balconies
* Security Deposit
* Price per Square Foot

The application also uses the **K-Nearest Neighbors (KNN)** algorithm to recommend nearby rental properties based on geographical coordinates.
